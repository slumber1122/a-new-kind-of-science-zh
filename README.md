# 一种新科学中文翻译

Stephen Wolfram《A New Kind of Science》的中文阅读版。

在线阅读：<https://slumber1122.github.io/a-new-kind-of-science-zh/>

当前收录范围为前言、第 1-12 章，以及注释至原 PDF 第 982 页。原书后续注释与索引尚未收入。

## 构建

生成本地单文件 HTML：

```bash
python3 scripts/build_translation_html.py
```

生成 GitHub Pages 站点：

```bash
python3 scripts/build_translation_html.py --pages
```
